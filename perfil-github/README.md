### &nbsp;&#9642;&nbsp; Sobre mí

Desarrollador **full stack con enfoque backend**. Diseño APIs REST en Python
(**Django / DRF**, **FastAPI**) y construyo las interfaces **React** que las
consumen, optimizando bases de datos relacionales y desplegando en la nube con
pipelines CI/CD.

Trabajo **freelance / por contrato**, disponible para proyectos remotos. Antes
construí **[PatinPay](https://patinpay.cl)** en solitario: una plataforma SaaS de
venta de entradas, tienda, rifas y streaming que llevé de cero a producción.
Ingeniero Industrial de formación → pensamiento analítico y orientación a procesos.

&#128205; Trinidad, Cuba &nbsp;·&nbsp; &#127760; 100 % remoto &nbsp;·&nbsp; &#128483;&#65039; ES nativo / EN A2–B1

### &nbsp;&#9642;&nbsp; Lo que hago

- **APIs** — Django REST Framework y FastAPI: auth JWT/OAuth2 con roles, documentación OpenAPI/Swagger, ~70 endpoints en producción.
- **Datos** — modelado y optimización en PostgreSQL / MySQL (−30 % de tiempo de respuesta en consultas críticas).
- **Frontend** — React + Vite + Tailwind, PWA, integración con pasarelas de pago, webhooks y streaming (LiveKit).
- **Entrega** — Docker, GitHub Actions, despliegue en Render / Cloudflare con dominio propio.
